# Resource submissions

This is the initial source-resource intake and publication area. Read the [submission pipeline guide](../docs/resource-publishing/submission-pipeline.md) for descriptor formats, approval/review, GitHub workflows, signatures, release assets, verification, and moving the workflow to another/private repository.

Submit data under `submissions/<resource-id>/` with a `submission.json` and a source directory/ZIP or locked public HTTPS archive descriptor. Maintainers control `policy.json`, `approvals/`, taxonomy, and trust. Approval is bound to exact canonical source ZIP bytes. Contributors must have redistribution permission before posting content in this public repository. Restricted/uncertain-rights works need private intake first.

The checked-in Romans study is an original CC0 **format/pipeline demonstration** with a fictional publisher identity. Its release is a signed source-stage preview, not an app-installable resource or a production taxonomy/catalog. All paid-resource commerce and entitlement behavior remains deferred.
