# Scripture share cards

Implemented in React/Tauri for selected text in Read. Select text (or use the existing whole-verse context selection), choose **Share passage**, then pick Quiet harbor or Olive hills and Portrait (1080×1350) or Square (1080×1080). The preview is the export canvas. The selected quotation, canonical reference/range and full active translation name/abbreviation are embedded into the PNG and included in the share caption. Attribution cannot be removed in the composer. Missing active-edition metadata blocks sharing rather than guessing a source; edition/content changes close any prepared card. Closing keeps the reading selection; creating a card does not create or modify a highlight.

Original generated painterly landscapes are bundled locally with [provenance and hashes](../../apps/fontes-web/public/art/share/provenance.json). The supplied screenshot informs atmosphere/brushwork rather than being used as a background. Fonts are the existing bundled Lora/Plex/Literary assets with their retained licenses. No network generation, external image fetch, quote upload or analytics is added at runtime.

The renderer waits for bundled fonts/image decoding, wraps explicit newlines and long words, and reduces quote size until the complete selection fits. A selection that cannot fit legibly is blocked with an explanation; it is never silently truncated. Failed image preparation is retryable. Changing format/background invalidates the previous prepared file immediately; generation checks discard stale completions. Only ready PNGs can be shared.

Android uses additive presentation IPC `share_verse_image`, not an engine command. It validates bounded PNG/caption input, writes an app-created UUID-named image into the app cache, and opens ACTION_SEND through a FileProvider content URI with temporary read permission and ClipData. The user chooses the destination in Android; the app does not select recipients or report delivery. Existing provider configuration is reused, no new storage permissions are added. Generated files older than seven days are removed on subsequent shares; Android may clear cache earlier. See [Android file sharing](https://developer.android.com/training/secure-file-sharing). JNI errors return to the composer for retry.

Browsers use prepared-file Web Share when supported and offer explicit PNG download, with automatic download fallback when file sharing is unsupported. The prepared file preserves the click's transient activation; generation is completed before Share becomes enabled. See [Web Share](https://www.w3.org/TR/web-share/). Native desktop sharing is explicitly unsupported by this first Android implementation; browser download works separately. Article/resource excerpts, saved-highlight list sharing, arbitrary image uploads, custom text editing and translation-specific publication-license enforcement are deferred. The current Scripture attribution does not assert permission to republish future licensed editions.

Compatibility: no engine commands, published contracts, canonical/annotation IDs, library snapshots, preferences or user DB migration changes. Only presentation assets, selection actions and platform sharing are added.
