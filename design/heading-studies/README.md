# Chapter heading typography studies

Local visual prototype; not an app implementation. Open `index.html` through the repository static server. Compares Pinyon Script, Cormorant Garamond Italic and Italianno, with unchanged Scripture body typography and a separate chapter label. Passage, palette and current-heading comparison controls are interactive; reader toolbar/navigation are visual context only.

New font files are from https://github.com/google/fonts/tree/main/ofl (pinyonscript, cormorantgaramond, italianno), with their SIL Open Font Licenses included in `fonts/`. Preview CSS embeds fonts for reliable in-app browser rendering; source TTFs remain alongside licenses. Existing Lora and IBM Plex Sans assets retain their existing repository licenses. Fonts have not been added to the application package.
